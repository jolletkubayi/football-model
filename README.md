# Football Model

Dixon-Coles match model with live fixtures for the PSL, CAF Champions League, CAF Confederation Cup,
UEFA Champions League, the top five European leagues and MLS. Fixtures and results come from ESPN's
public scoreboard feed. Enter bookmaker odds on any match to see the edge and a suggested stake.
